# D-015 — Agent ใหม่ต้องมีหลักฐานจาก Evaluation

- ADR: 0015
- Decision ID: D-015
- สถานะ: Accepted
- วันที่: 2026-07-04
- อ้างอิง: AIO-1.1-BLUEPRINT-v1.2, AIO-1.1-DECISIONLOG-CONFIRM-2026-07-04

## บริบท (Context)
การเพิ่ม agent โดยไม่มีการวัดผลทำให้คุณภาพควบคุมไม่ได้

## การตัดสินใจ (Decision)
agent ใหม่ทุกตัวต้องมีหลักฐานผ่าน Evaluation ก่อน promote

## ผลที่ตามมา (Consequences)
คุมคุณภาพ agent; มีผลเต็มที่ Phase 2 (พึ่ง Golden Dataset D-011)
