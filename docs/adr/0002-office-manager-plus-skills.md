# D-002 — ใช้ Office Manager หนึ่งตัว + Skills ใน MVP

- ADR: 0002
- Decision ID: D-002
- สถานะ: Accepted
- วันที่: 2026-07-04
- อ้างอิง: AIO-1.1-BLUEPRINT-v1.2, AIO-1.1-DECISIONLOG-CONFIRM-2026-07-04

## บริบท (Context)
ต้องกำหนดรูปแบบ orchestration ของ agent ใน MVP

## การตัดสินใจ (Decision)
ใช้ Office Manager 1 ตัวเป็นตัวประสาน + Skills เป็นหน่วยงานย่อย แทนการมีหลาย manager

## ผลที่ตามมา (Consequences)
โครงเรียบง่าย ตรวจสอบง่าย; Office Manager/Skills เป็นงาน Phase 2 — ห้ามเริ่มใน Phase 1
