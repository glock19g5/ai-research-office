# D-010 — CrewAI ใช้แบบ provisional

- ADR: 0010
- Decision ID: D-010
- สถานะ: Accepted
- วันที่: 2026-07-04
- อ้างอิง: AIO-1.1-BLUEPRINT-v1.2, AIO-1.1-DECISIONLOG-CONFIRM-2026-07-04

## บริบท (Context)
repo เดิมใช้ CrewAI แต่ยังไม่ยืนยันเป็น framework ถาวร

## การตัดสินใจ (Decision)
รับ CrewAI แบบ provisional — ใช้ pattern อ้างอิงได้ แต่ยังไม่ผูกตายกับสถาปัตยกรรม, ทบทวนอีกครั้งใน Phase 2

## ผลที่ตามมา (Consequences)
ยืดหยุ่นต่อการเปลี่ยน orchestration; Phase 1 ไม่พึ่ง CrewAI
